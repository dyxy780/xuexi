# 第1周：软件测试基础与测试思维

目标：建立软件测试的基础认知，掌握基本术语与测试流程。

每天安排（每天约2小时）：

- 周一：测试概念与流程
  - 学习软件测试的定义、目的、基本术语（缺陷、测试用例、用例覆盖率等）。
  - 阅读测试生命周期（需求分析 -> 测试计划 -> 设计用例 -> 执行 -> 提交缺陷 -> 回归）。

- 周二：测试类型与测试阶段
  - 熟悉单元测试、集成测试、系统测试、验收测试、冒烟测试与回归测试的区别与适用场景。
  - 理解白盒测试与黑盒测试的基本概念。

- 周三：需求分析与测试计划
  - 练习从需求文档中提取测试点。
  - 学习如何编写简单的测试计划与范围说明。

- 周四：测试用例设计方法
  - 掌握等价类划分、边界值分析、判定表、状态迁移等常用设计方法的理���与示例。
  - 实践编写至少5条手动测试用例。

- 周五：缺陷管理基础
  - 学习缺陷生命周期、严重级别与优先级的定义。
  - 使用缺陷模板提交示例缺陷（可用Excel或Issue模拟）。

- 周六：测试环境与测试数据
  - 理解测试环境搭建要点（数据隔离、可重复性）。
  - 练习准备测试数据（正例与异常数据）。

- 周日：复盘与练习
  - 汇总本周学习笔记，整理常见术语表。
  - 回顾并完善本周编写的测试用例与缺陷示例。

检查点：能用自己的话描述测试流程，完成至少10条基础测试用例并能上交缺陷示例。
